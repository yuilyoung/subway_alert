# 지하철 하차 알림 — 개발 중인 Android MVP

React Native/Expo Android 앱과 Spring Boot 추적 도메인 프로토타입입니다. **현재 데모이며 실제 하차 판단이나 운행 안내를 대신할 수 없습니다.** 서울시 공개 샘플 열차 목록을 서버에서 조회하고 앱에 표시하는 시험 기능이 있습니다. 공개 샘플을 이용한 시험 감시와 FCM 전송 코드가 있으나 실제 자격 증명·기기 수신은 미검증이고 실제 하차 알림은 차단되어 있습니다. Supabase는 미연동입니다. 지하 GPS·백그라운드 제한과 추정 좌표 때문에 실제 1정거장 전 알림은 보장되지 않습니다.

## 현재 구성

- `mobile/`: 일부 2호선 샘플 역 검색, 출발·도착 선택, 최대 5개 즐겨찾기, 요일/시간 및 위치 기반 데모 감시와 서버 열차 조회 화면. 좌표는 검증되지 않았습니다. 앱 내 각 표시를 확인하세요.
- `server/`: 서울시 공개 샘플 열차 조회와 열차 ID·방향을 지정하는 데모 추적 API 및 수동 이벤트 처리. 메모리 기반이며 서버 재시작 시 삭제됩니다. 앱과 서버는 시험 세션과 시험 FCM 요청을 연동하며, 실제 FCM 자격 증명 및 기기 수신은 미검증입니다.
- `data/`: 별도 예시 역 목록. 검증된 좌표·시설 정보는 없고 앱에서 직접 사용하지 않습니다.
- `supabase/`: 실행하거나 적용하지 않은 스키마 초안입니다.
- 원본 설계 PDF는 사용자 제공 첨부 파일이며 공개 저장소에는 포함되지 않았습니다.

## 실행 및 테스트

각 폴더의 README에서 세부 명령과 전제조건을 확인하세요. 모바일에는 Node.js, npm, Android SDK 또는 Expo 개발 환경이 필요합니다. 실제 백그라운드 위치 기능은 개발 빌드와 Android 기기 권한이 필요하고 Expo Go로 검증할 수 없습니다. 서버 전체 빌드에는 JDK 17과 Maven이 필요합니다.

```sh
cd mobile
npm install
npm test
npx expo run:android
```

```sh
cd server
mvn test
mvn spring-boot:run
```

```sh
python3 -m unittest discover -s data/tests -v
```

## 외부 서비스 및 미완료

서울 열린데이터광장 실시간 열차 위치 API는 인증키가 필요합니다. 공개 샘플은 최대 5건이며 전체 운행 목록이 아닙니다. 실제 키를 이용한 HTTPS 연결은 미검증입니다. 공개 샘플 기반 시험 세션은 서버에서 공유 폴링하며 실제 탑승 및 경로를 확인하지 못합니다. 실제 하차 추적은 차단되어 있습니다. FCM 시험 전송에는 앱의 Firebase 설정, 서버 자격 증명 및 Android 기기가 필요하며 실제 전송과 수신은 미검증입니다. Supabase는 별도 프로젝트 선택·인증·마이그레이션·RLS 검증이 필요하며 미연동입니다. 빠른 환승·화장실·개찰구·출구·편의시설의 공식 자료도 확보되지 않아 실제 정보를 제공하지 않습니다. 모든 역과 환승/급행/순환 노선, 안정적인 출퇴근 자동 감지, 재부팅/Doze/강제 종료 후 복구, 실기기 테스트, 배포 빌드는 미완료입니다.

**보안:** API 키, 서비스 역할 키, FCM 개인 키를 저장소나 앱에 넣지 마세요. 민감한 설정은 서버 환경 변수 및 안전한 비밀 저장소로 관리해야 합니다.
