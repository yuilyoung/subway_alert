# 데모 역 데이터

`stations.sample.json`은 2호선 삼성→선릉→역삼→강남→교대 순서의 **일부 구간을 설명하는 샘플**입니다. 전체 2호선/지선이 아니며 샘플의 양 끝은 연결되어 있지 않습니다. `demo-` ID는 이 샘플에서만 사용하는 식별자로, 서울시 API의 역 ID가 아닙니다. 앱에서 사용하려면 이 파일을 번들에 명시적으로 포함해야 합니다.

위치 좌표와 빠른 환승·화장실·편의시설·개찰구·출구 정보는 확인된 값을 확보하지 못해 `null`입니다. `null`은 '시설이 없음'이 아니라 **정보 미확인**을 의미합니다. 이 데이터는 위치 감지·지오펜스·실제 하차 판단에 사용할 수 없습니다. 실서비스에서는 검증된 좌표와 역/호선/방향/지선의 관계, 역 시설의 출처 및 갱신시점을 확보하고 API 역 코드와 명시적으로 매핑해야 합니다. 역 정보가 변경되거나 위치 정보가 부정확할 수 있으므로 데이터 이용 조건과 갱신주기도 확인해야 합니다.

데이터 출처 후보:

- [서울시 역사마스터 정보](https://data.seoul.go.kr/dataList/OA-21232/S/1/datasetView.do): 역사 ID, 이름, 노선, 좌표 정보.
- [서울교통공사 1~8호선 역사 좌표 정보](https://data.seoul.go.kr/dataList/OA-22534/L/1/datasetView.do): 역사 위경도 파일. 파일의 최신성 및 이용 조건 확인 필요.
- [서울시 지하철역 연계 지하도 공간정보](https://data.seoul.go.kr/dataList/datasetView.do?infId=OA-21213&serviceKind=1&srvType=S): 지하도 출입구 간 연결 정보. 설명상 2020년 기준이므로 현행성 확인 필요.

검증: 저장소 루트에서 `python3 -m unittest discover -s data/tests -v` 실행.
