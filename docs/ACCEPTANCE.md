# 실기기 인수 테스트 — 아직 수행하지 않은 항목

자동 단위/통합 테스트 통과가 실제 탑승·Android 백그라운드 수신 검증을 대신하지 않습니다.

## Android
- API 24, 29, 30, 33, 36 기기/에뮬레이터에서 수동 경로 설정 및 취소.
- 알림 허용/거절, 알림 채널 비활성화, 방해금지, 배터리 제한, 화면 잠금, 최근 앱 제거, 명시적 강제 종료를 각각 구분.
- FCM 알림: 화면 켜짐/잠김/Doze/프로세스 재생성, token refresh, 네트워크 단절 후 만료 메시지 제거.
- 같은 eventId 재전송은 한 번만 표시. 취소한 sessionId는 표시하지 않음.
- 위치 권한 거절 상태에서도 수동 추적이 가능. 자동 설정은 단계별 foreground/background 동의를 요구.
- 부팅/앱 업데이트 뒤 지오펜스 복원, 진입 지연, 경계 주변 위치 오차, 동일 위치 복수 경로.
- 금요일 23:00~토요일 02:00, 일요일~월요일 경계, 하루 재진입, 서버 응답 직후 프로세스 종료.
- 화면 확대/큰 글꼴, TalkBack, 키보드가 열린 상태의 검색 결과 선택.

## 실제 열차
- API 원본 trainNo/방향/역 ID/종착역/급행 필드와 앱 표시 일치 확인.
- 실제 승차 열차 선택 후 직전역 출발 시각, 서버 판단 시각, FCM 승인, 기기 표시 시각을 별도로 기록.
- 순환선, 지선, 단축 운행, 급행 제외, 역 통과, API 시간 역전 및 90초 초과 지연.
- 한 정거장 이동, 목적지 도착 후 뒤늦게 받은 관측, 취소-발송 경쟁.
- 환승 포함 여행은 현재 지원 범위가 아님을 UI에서 확인.

## 배포 전
- 검증된 역/시설 자료 적재 및 데이터 라이선스/출처 표시 확인.
- live 프로필, HTTPS, 비밀 환경변수, 전용 DB 소유자 역할, 비공개 schema 접근 제한.
- Firebase 익명 로그인 남용 방지(App Check/추가 rate limit), 프록시 제한, 개인정보/위치정보 안내.
- 의존성 지원 종료/보안 패치 검토, 서명키 분리, Google Play 백그라운드 위치 정책 검토.
- 프로덕션 release는 별도 서명 설정. preview APK는 테스트 서명이며 스토어 배포용이 아님.
